# Optional extras (not part of the main lab)

The main lab is **check, trace, fix, prove** on the existing model. These skills build a new model from the gold tables. To use one, copy its folder into `.github/skills` (`build-from-gold`) or rename `validate-answer-key-gold.SKILL.md` to `SKILL.md` inside a new `.github/skills/validate-answer-key-gold` folder, then reload the VS Code window.
